# Lista de Chequeo de Calidad (QA Checklist)

- [ ] **PWA & Offline:** El Service Worker se registra correctamente y la app es instalable (Lighthouse PWA > 90).
- [ ] **Presupuesto (100M):** No permite confirmar plantilla si el costo excede los 100 Millones.
- [ ] **Alineación Completa:** Verifica que haya exactamente 11 jugadores antes de simular.
- [ ] **Penalizaciones Tácticas:** Se aplica y visualiza el 15% o 25% de reducción al colocar jugadores fuera de posición.
- [ ] **Autenticación:** Las rutas protegidas redirigen a login si no existe token JWT válido.
- [ ] **Responsividad:** La interfaz funciona de forma fluida en pantallas móviles (360px+) y escritorio.
